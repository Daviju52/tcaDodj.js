🎮 Jogo de Adivinhação de Palavras
📌 Sobre o projeto

Este projeto consiste em um jogo de adivinhação de palavras, no qual o jogador precisa descobrir uma palavra secreta de 5 caracteres em até 5 tentativas.

A cada tentativa, o jogo fornece dicas para ajudar o jogador a descobrir a palavra correta.

🎯 Objetivo

Adivinhar a palavra secreta antes que as 5 tentativas acabem.

🕹️ Como funciona?

O jogo escolhe uma palavra secreta de 5 caracteres.

O jogador digita uma palavra com 5 caracteres.

O sistema verifica a tentativa e fornece dicas:

🟩 Verde: o caractere está correto e na posição certa.

🟨 Amarelo: o caractere existe na palavra, mas está na posição errada.

🟥 Vermelho: o caractere não existe na palavra.

O jogador tem até 5 tentativas para acertar.

Se acertar, vence o jogo. Caso contrário, perde e a palavra correta é revelada.


📋 Regras

O jogador possui apenas 5 tentativas.

Não é permitido enviar palavras com quantidade maior de 5 caracteres.

O jogo termina quando o jogador acerta ou esgota as tentativas.


💻 Tecnologias utilizadas

JavaScript

HTML


🚀 Como executar

Faça o download ou clone este repositório.

Abra o projeto em sua IDE ou editor de código.

Execute o arquivo principal.

Comece a jogar e tente descobrir a palavra secreta!
